# Restore delegated research without widening credential access

In a project that has enabled web research and granted permission on the local
computer, a delegated research specialist cannot use its research tools. The
same tools work in the parent session.

Make delegated research honor the project's actual permission decision and
credential route. An authorized research specialist must be able to perform a
loopback-fixtured research request in both project and user state modes. A
denied project must remain denied, unrelated specialist roles must not receive
the research credential, and credentials or unrelated session state must not
appear in results or logs. Use placeholder credentials only.
