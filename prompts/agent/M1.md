# Preserve Windows crash exit codes

Kiln's Windows job host loses a child process exit code when the process ends
with a Windows crash status at or above `0x80000000`. The supervisor reports an
ordinary exit code instead, and the normal shutdown bookkeeping is incomplete.

Correct the behavior so the original 32-bit crash status is recorded, the host
finishes its normal release path, and no child or host process is left behind.
Preserve the existing behavior for ordinary successful and unsuccessful child
process exits. Add or update Windows-native tests that demonstrate the result.
